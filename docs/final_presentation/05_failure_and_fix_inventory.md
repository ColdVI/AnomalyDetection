## En önemli metodolojik düzeltme

Projenin tekrar eden ana düzeltmesi “daha karmaşık model” değil, **ölçüm zincirini düzeltmek** oldu: fiziksel gözlenebilirlik → doğru truth → bağımsız grup split’i → train-only preprocessing → random/magnitude kontrolü → event politikası → bağımsız normal alarm yükü. Kaynak: `docs/PROJE_YASAYAN_CALISMA_GUNLUGU.md`; `configs/four_dataset_probabilistic_v31_evaluation_contract.json`.
